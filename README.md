# Xray-Sing-node

A collection of scripts to deploy high-performance proxy services on various hosting platforms including Node.js, Python, and Java-based Minecraft servers.

![](https://iili.io/CPU7vh7.png)

## 🚀 Features

- **Protocol Support**: Xray VLESS ARGO and SingBox Hysteria2, VLESS WS
- **Multi-Platform Deployment**: Node.js, Python, and Java environments

## 📋 Supported Protocols
- *Xray + Argo Tunnel*
- *SingBox + Hysteria2 + VLESS WS*

## 🛠️ Deployment Targets

- **Node.js Hosting Platforms**
- **Python Application Servers**
- **Java Minecraft Servers**
